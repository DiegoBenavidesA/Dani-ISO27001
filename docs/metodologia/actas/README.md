# Actas de reunión

Esta carpeta guarda el registro de las reuniones del equipo desde el sprint de cierre (noviembre de 2026). Hasta el sprint 4 las reuniones se hicieron por Google Meet sin actas; ver la sección 5 del [Sprint Backlog](../Sprint_Backlog.md).

## Cómo registrar una reunión

1. Al terminar la reunión, quien la anota copia [`_plantilla_reunion.md`](_plantilla_reunion.md) y la guarda con la fecha de la reunión: `AAAA-MM-DD.md` (por ejemplo, `2026-11-17.md`). Si hay dos reuniones el mismo día, se agrega un sufijo: `2026-11-17-b.md`.
2. Completa solo lo que se habló. Si un apartado no aplica, se deja "Sin novedades"; nunca se inventa contenido.
3. Hace el commit el mismo día, con el mensaje `docs(actas): reunión AAAA-MM-DD`. La fecha del commit es la evidencia de que el acta se escribió en ese momento.
4. La persona que anota rota en cada reunión, para que los tres aparezcan en el historial.

Para la reunión de cierre de un sprint se usa [`_plantilla_retrospectiva.md`](_plantilla_retrospectiva.md), y después se resume en [Retrospectivas](../Retrospectivas.md).

## Reuniones programadas

Las reuniones se agendan como evento recurrente en Google Calendar, con el enlace de Meet, para que quede registro de su frecuencia. El horario acordado se anota en el acta de la primera reunión del sprint de cierre.
